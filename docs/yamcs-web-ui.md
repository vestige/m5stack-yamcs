# YAMCS Web UI のメニュー

YAMCS 5.13 の Web UI（http://localhost:8090）で、インスタンスを開いたときの左メニューの一覧です。各メニューが何をする所か、衛星運用ではどんな役割を持つかをまとめています。

表示されるメニューは、インスタンスの設定やユーザーの権限によって変わります。たとえば Timeline は `TimelineService` を、File transfer はCFDPのサービスを設定したときだけ表示されます。

| メニュー | サブメニュー | 何をする所か | 衛星運用での役割 |
| --- | --- | --- | --- |
| **Home** | | インスタンスの概要 | 運用の入口 |
| **Links** | | データリンク（通信路）の一覧。受信数の確認や、リンクの有効・無効の切り替え | 地上局と衛星の回線の監視。リンクを無効にすれば、通信が途切れた状態（パスの終わり）を再現できる |
| **Telemetry** | Packets | 届いたパケットを1つずつ、中身のバイト列と一緒に見る | 受信したデータの確認 |
| | Parameters | パラメータの現在値・グラフ・履歴 | 衛星の状態監視の中心 |
| | Parameter lists | よく見るパラメータを自分で一覧にまとめる | 運用者用の監視画面 |
| | Displays | 自作の画面（ダッシュボード）を置いて表示する | 運用卓の画面 |
| **Algorithms** | | MDBで定義した計算処理の実行状況 | 派生パラメータの確認（移動距離など） |
| **Events** | | イベント（文章のメッセージ）の時系列一覧。上部の ▶（Start streaming）ボタンでライブ表示になり、届いたイベントがリロードしなくても追加される | 「SAFEに移行した」「コマンドを拒否した」などの記録 |
| **Alarms** | | 発生中のアラームの一覧。確認（Acknowledge）や一時的な抑制（Shelve）ができる | 異常への対応。誰がいつ確認したかが残る |
| **Commanding** | Send a command | MDBで定義したコマンドを選び、引数を入れて送る | 衛星の操作 |
| | Command history | 送ったコマンドと、受理・実行完了などの結果 | Command Verificationの確認 |
| | Queues | 送信前のコマンドを溜めておく待ち行列。人が承認してから送る、という運用ができる | 重要なコマンドの承認フロー |
| | Clearances | 運用者ごとに、送ってよいコマンドの重要度の上限を決める | 権限管理 |
| **File transfer** | | 衛星と地上の間でファイルを送受信する（CFDP） | 観測ファイルのダウンロードなど |
| **Procedures** | Stacks | 複数のコマンドを順番に並べた「コマンドスタック」を作って実行する | 運用手順書。「観測開始手順」など |
| | Run a script | 運用スクリプトを実行する | 手順の自動化 |
| **Timeline** | Bands など | 時間軸の上に予定（アイテム）を帯（バンド）状に並べる | 運用計画。パスや観測の予定 |
| **Activities** | | 手順やスクリプトの実行記録 | 誰がいつ何を実行したかのログ |
| **Mission database** | Overview / Parameters / Parameter types / Containers / Commands / Algorithms | 読み込んだMDBの中身を閲覧する | 定義の確認 |
| **Archive browser** | | 保存されたデータを時間軸で俯瞰する。データの抜け（途切れ）もわかる | パス後の振り返り、記録データの後送りの確認 |

メニューの一覧は、YAMCS 5.13.0 のソースコード（`yamcs-web` の `instance-layout.component`）をもとにしています。
